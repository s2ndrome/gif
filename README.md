# SEOL GIF

영상을 잘라 사진 효과를 입히고 **GIF**로 저장하는 정적 웹 도구입니다.
[SEOL MP4](https://github.com/s2ndrome/mp4)의 화면 구성과 사진 효과를 그대로 가져와 영상 프레임에 쓰도록 옮겼어요.
모든 처리는 브라우저 안에서만 하고, 영상은 어디에도 올라가지 않습니다.

## 기능

- **AI 영상** (그림 한 장 → 움직이는 영상, Google Vertex AI · Veo)
  - 그림 넣기(고르기 · 끌어다 놓기 · 붙여넣기), 움직임 문구 버튼(머리카락 · 옷자락 · 줌인 · 눈 · 꽃잎 …) + 프롬프트 직접 쓰기
  - 모델 Veo 3.1 Fast / Veo 3.1 (직접 입력 가능), 4 · 6 · 8초, 16:9 · 9:16(그림에 맞춰 자동), 720p · 1080p, 소리, 시드
  - 완성되면 MP4 다운로드 또는 **바로 GIF 만들기로 넘기기**
  - 연결: 프로젝트 ID + 지역 + 액세스 토큰(`gcloud auth print-access-token`, 1시간 유효) 또는 API 키
  - 토큰은 브라우저에서 `aiplatform.googleapis.com`으로만 바로 보내고, 기본은 탭을 닫으면 지워짐(원하면 '기억하기'). 저장소에는 토큰을 넣지 않아요.
- **영상**
  - 파일 고르기 / 끌어다 놓기 / 붙여넣기(Ctrl+V · ⌘V) — mp4 · mov · webm
  - 필름 띠를 보며 구간 자르기 (1초 / 2초 / 3초 / 5초 / 전체 / 재생 위치부터)
  - 속도 0.25×~4×, 방향: 정방향 · 거꾸로 · **부메랑**
  - 꽉 채우기 / 전체 보이기(흐린 영상 · 단색 배경), 확대·위치 조절 (미리보기 드래그 · 휠)
  - 글자 넣기: 글꼴 6종, 위치·정렬, 서서히/타자 치듯 나타나기
- **효과** (SEOL MP4와 같은 코드)
  - 필터 14종 + 밝기·대비·채도·색온도·바램·빛 번짐 직접 조절
  - 움직임 7종: 줌인/줌아웃, 좌우 이동, 둥실둥실, 손떨림, 쿵쿵, 기울기
  - 효과 16종: 필름 노이즈, 먼지·스크래치, VHS, RGB 분리, 글리치, 주사선, 깜빡임, 빛 번짐, 빛망울, 비네팅, 눈, 비, 반짝이, 하트, 꽃잎, 시네마 바
  - 캠코더 날짜, 화면 페이드 인/아웃
  - (음악에 반응하던 음파 라인 · 이퀄라이저는 GIF에 소리가 없어서 뺐고, 비트 펄스는 일정한 박자의 '쿵쿵'으로 바꿨어요)
- **저장**
  - **목표 용량** (제한 없음 · 1~15MB · 직접 입력): 넘으면 디더링 → 크기 → 초당 프레임 → 색 수 순서로 줄여서 그 안에 맞춤
  - **예상 용량** 미리 표시 (영상에서 몇 장을 실제로 GIF로 묶어 보고 계산), 저장 중엔 지금까지 크기, 끝나면 최종 MB
  - 원본 · 1:1 · 4:5 · 9:16 · 16:9, 크기 240~720px, 8~25fps
  - 색 수 16~256, 디더링(Floyd–Steinberg) 강도, 팔레트 프레임마다 / 하나로 통일
  - 계속 반복 / 한 번만 / 3번
  - 모바일에서는 공유 버튼으로 사진 앱에 바로 저장
- 설정은 이 브라우저에 자동 기억

## 배포 (GitHub Pages)

빌드 과정 없이 파일 그대로 배포됩니다.

1. 저장소 **Settings → Pages**
2. **Source**: `Deploy from a branch`, **Branch**: `main` / `/ (root)` → Save
3. 잠시 후 `https://s2ndrome.github.io/gif/` 에서 열립니다.

로컬에서 보려면: `python3 -m http.server` 후 `http://localhost:8000`
(ES 모듈을 쓰기 때문에 `index.html`을 더블클릭해서 여는 방식으로는 동작하지 않아요.)

## 파일

- `index.html` – 화면
- `style.css` – 스타일 (SEOL MP4와 같은 무드)
- `js/app.js` – 상태, 영상 넣기, 구간·속도·방향, 미리보기
- `js/image-fx.js` – 필터·움직임·효과 그리기 (미리보기와 저장이 같은 코드)
- `js/ai-video.js` – AI 영상: Vertex AI Veo 요청(predictLongRunning) · 진행 확인(fetchPredictOperation) · 결과 받기
- `js/gif.js` – 프레임 꺼내기, 색 줄이기·디더링, GIF 묶기, 용량 측정
- `vendor/gifenc.js` – GIF 인코더 (MIT, gifenc v1.0.3)
